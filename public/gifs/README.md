# GIFs for Impact Page Hero Section

Place your animated GIFs in this directory to use them in the Impact page hero section.

## Recommended GIF Topics (related to Seevora):

1. **AI/Machine Learning** - Neural networks, AI processing, robot animations
2. **Data Analytics** - Charts, graphs, data visualization
3. **Business Growth** - Upward trends, growth charts, success metrics
4. **Automation** - Gears, workflows, process automation
5. **Technology** - Coding, digital transformation, cloud services

## GIF Specifications:

- **Format**: GIF (animated)
- **Size**: Recommended 500x500px to 800x800px
- **File Size**: Keep under 2MB for optimal loading
- **Background**: Transparent or solid background works best

## How to Use Your Own GIFs:

1. Place your GIF files in this `public/gifs/` directory
2. In `src/components/landing-page/ImpactPage.jsx`, replace the Giphy URLs with:
   - `"/gifs/your-filename.gif"`

Example:
```jsx
<img 
  src="/gifs/ai-automation.gif" 
  alt="AI automation"
  style={{...}}
/>
```
